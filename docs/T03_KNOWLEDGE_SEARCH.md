# T03 — 오프라인 지식 검색 모듈

상태: 검색 계층 구현 및 테스트 단계. T02 [Knowledge Builder](T02_KNOWLEDGE_BUILDER.md)에서 생성한 `schema_version=1` SQLite DB를 읽습니다. HTTP API(T05), LLM 호출(T04), 설치/배포(T07)는 포함하지 않습니다.

## 사용 예제

```python
from search.knowledge_search import search_documents, match_event

hits = search_documents(
    "output/knowledge.db",
    product_id="example-program",
    version="2.10.0",
    query="DB-1001 연결 실패",
    limit=10,
)

help_info = match_event(
    "output/knowledge.db",
    product_id="example-program",
    version="2.10.0",
    error_code="DB-1001",
    event_id="connection_failed",
    screen_id="database_settings",
)
```

- `search_documents()`: 문서 ID, 청크 ID, 제목, 절 제목, 원문 발췌, 원본 상대 경로, PDF 페이지 번호를 반환하며 AI 답변은 생성하지 않습니다.
- `match_event()`: 사전 승인된 오류·이벤트 안내문과 출처를 반환하며 **LLM을 호출하지 않습니다**.
- 두 함수 모두 **읽기 전용**으로 DB를 열고 정확한 제품 ID로 범위를 제한합니다. DB 스키마 버전이 맞지 않으면 실행하지 않습니다.

## 제품·버전 적용 규칙

1. `product_id`는 **완전 일치**해야 합니다. 제품 간 문서를 섞지 않습니다.
2. 버전은 `1`, `1.2`, `1.2.3`, `2026.11` 등 숫자와 점으로 구성된 형식만 지원합니다. `2.10`은 `2.9`보다 큽니다. `2.0`과 `2.0.0`은 같습니다.
3. `version_from`과 `version_to`는 **경계 포함**입니다. 규칙이 문서를 참조하면 문서와 규칙의 버전 범위 모두 만족해야 합니다.
4. 요청 버전이 없으면 버전 제한 없는 문서·규칙만 반환합니다. 버전 접미사(`1.0-beta`, `7.4.33-pl1`, `v2.0`)는 이번 버전에서 미지원입니다. 요청이 해당 형식이면 오류를 표시하고, 자료에 해당 형식이 있으면 비매칭으로 처리합니다.
5. 다른 제품 버전 규칙을 자동 추측하지 않습니다. 비숫자 버전 지원은 별도 계약이 필요합니다.

## 오류·상태 이벤트 정책

- `event_id` 또는 `error_code` 하나 이상을 제공해야 합니다.
- 규칙에 존재하는 `event_id`, `error_code`, `screen_id`는 모두 요청값과 일치해야 합니다. 규칙에 없는 항목은 제한 조건으로 적용하지 않습니다.
- 여러 규칙이 매칭되면 **이벤트/오류 지정 개수 → 화면 지정 여부 → 버전 경계 지정 개수** 순으로 구체적인 규칙을 선택합니다.
- 가장 높은 우선순위의 규칙이 여러 개 남으면 `{"matched":false,"reason":"ambiguous_rules"}`를 반환합니다. 임의로 하나를 고르지 않습니다.
- 매칭 규칙이 없으면 `{"matched":false}`를 반환합니다. 이 경로에서 LLM에게 해결 방법을 생성시키지 않습니다.
- 이 규칙은 **T03 내부 모듈 계약**이며 HTTP API의 최종 응답 구조와 상태 코드는 T05에서 다룹니다.

## 검색 정확도와 알려진 한계

- 자유 질의를 유니코드 영숫자 토큰으로 분리하고 각각 FTS5 인용부호 안에 넣어 OR 검색합니다. SQL 파라미터 바인딩으로 삽입합니다.
- FTS5의 `bm25` 순위로 정렬하고 동점이면 원본 경로·청크 순서로 정렬합니다.
- SQLite `unicode61`은 한국어 형태소 분석을 하지 않습니다. `실패`가 `실패를`에 매칭되지 않을 수 있으며 동의어 확장도 없습니다.
- OR 검색에서는 일부 단어만 일치해도 결과가 나옵니다. 이는 의미 검색이나 정답 보증이 아닙니다.
- 모든 후보의 버전을 확인한 뒤 응답 개수를 제한합니다. 매우 큰 문서 DB의 검색 성능 최적화는 후속 측정 사항입니다.
- 추가 임베딩/형태소 검색 엔진은 이번 T03에 포함하지 않습니다.
